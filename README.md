# ♠ Блэкджек Академия

Тёмная, атмосферная 2D-игра «Блэкджек» на чистом HTML/CSS/JavaScript — с полным интерактивным обучением для абсолютных новичков, подробным разбором каждой раздачи и матча, а также **самообучающейся нейросетью-дилером** (2 скрытых слоя, Q-обучение, сохранение/загрузка весов в JSON, живой график прогресса).

## ✨ Возможности

### 🎮 Игра
- Классический блэкджек: **Ещё / Хватит / Удвоить**, ставка фишками (10–500), банк, шуз из 4 колод с автоперемешиванием.
- Два соперника на выбор: **Бот** (строгие правила дилера: <17 берёт, ≥17 стоит, проверка блэкджека) или **Нейросеть** (свободный дилер, который учится побеждать вас).
- **Матч до 3/5/7/10 побед**, счёт, история раздач, статистика сессии (победы, блэкджеки, серия, точность решений,净 результат).
- Блэкджек платит **3:2**, ничья возвращает ставку, бесплатная докупка фишек при банкротстве.
- Подсказки базовой стратегии с объяснением «почему» — прямо у стола (отключаемые).
- Анимации раздачи/переворота карты, конфетти, полёт фишек, синтезированный звук (WebAudio, без аудиофайлов), кнопка mute в шапке.

### 🎓 Обучение (16 шагов, для «полностью нулевого» человека)
Что такое блэкджек и зачем в него играют → колода и масти → стоимость карт (**интерактивный счётчик руки**) → мягкие/твёрдые руки → цель и перебор → анатомия раздачи (**интерактивный степпер**) → три действия → правила дилера и отличие нейросети → блэкджек и выплата 3:2 → фишки и банк → **3 квиза с разбором ответов** → шпаргалка базовой стратегии (цветная таблица) → ** guided-практика: настоящая раздача с подсказками** → финал с чек-листом.

### 🧠 Нейросеть
- MLP **7 → 16 → 12 → 2** (два скрытых слоя, tanh, линейный выход Q-значений).
- **Q-обучение** с опытом-реплеем (20 000), Adam, ε-greedy с затуханием, самоигра против игрока базовой стратегии + **онлайн-дообучение на ваших партиях**.
- Живой график: победы дилера (MA-200), ε, пунктир — измеренный уровень классического бота; спарклайн ошибки TD; лента последних 60 исходов.
- **Экспорт/импорт весов в JSON**, автосохранение в localStorage, сброс сети, визуализация архитектуры и «уверенности» сети при каждом ходе.

### 📖 Разборы
- В конце **каждой раздачи**: кто победил и почему, подсчёт очков по картам (включая сброс туза), пошаговый ход раздачи с решениями и причинами, арифметика выплаты, аудит ваших решений по базовой стратегии и совет.
- В конце **каждого матча**: подробный отчёт — таблица всех раздач с причинами (клик по строке открывает полный разбор), суммы, точность, вердикт.

### 📱 Адаптивность
Полноценные раскладки для desktop / планшета / телефона: липкая панель действий снизу на мобильных, кастомные скроллбары, `safe-area`, крупные тач-цели.
